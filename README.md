# Python Practice Projects

Small Python projects I built while following the Udemy course *100 Days of Code: The Complete Python Pro Bootcamp*, as part of my professional learning plan for 43030 Professional Practice in Computing at UTS.

| Project | Description |
| --- | --- |
| [Coffee Machine](coffee-machine/) | Command-line coffee machine with resource checks and coin payments |
| [Higher Lower Game](higher-lower/) | Guess which account has more followers; keeps score until a wrong answer |

## How to run

Each project is in its own folder. Open the folder and run:

```bash
python3 main.py
```
